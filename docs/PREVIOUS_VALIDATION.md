총 18개 정상 게임은 모두 종료했다. Return은 허용오차 1e-6 이내이고 에피소드 길이·업적 벡터는 정확히 일치했다. 두 개입 월드는 원래 자료에서 개입이 있었던 사례를 골라 실행 경로를 확인했다. 따라서 무작위 성능 검증 표본이 아니다. 모델 8개 전체의 대규모 평가를 새로 실행한 것은 아니다.

감사 전이와 원래 엔진 전이는 실제 초기 상태 128개에서 전체 다음 물리 상태·공개 관측·보상·종료가 정확히 일치했다. 비교 때문에 256회 전이 호출 및 128회 Reset을 사용했다. 실제 PPO·Skill forward, 확률 합, M2 허용 행동, Planner smoke도 통과했다.

CSV 기반 주요 표 검산은 원본 연구 경로 없이 통과했다. 전체 160개 NPZ 재검산은 경량 배포에서 제외했다. 신규 학습, Optimizer 업데이트, 유료 API 호출은 0이다. 새 Windows 가상환경 설치 및 새 GPU 실행은 이번 검증 범위에 포함하지 않았다.

정확한 행과 수치는 validation/의 대응 CSV 및 JSON을 확인한다. 실행 예제와 전체 평가 계약은 README.md에 있다.
