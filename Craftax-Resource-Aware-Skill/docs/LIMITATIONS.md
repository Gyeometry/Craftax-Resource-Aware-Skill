# 한계와 반례

- 단일 Craftax-Classic 및 관련 제작 목표 중심 평가다.
- 목표 의미·공개 지도 해석·Planner·자원 비용 합성 템플릿에 제공된 사전지식이 있다.
- Skill은 BC 학습이며 기본 PPO의 From-scratch 학습 성능 개선 주장이 아니다.
- 1회 호출/16 Primitive는 개입 비용과 비교 범위를 고정한 설계다. 최적 호출 횟수의 실험적 보장은 없다.
- 자원 조건은 시작 상태·시점을 바꾸므로 완료율 차이를 동일 상태의 실행 능력 차이로 해석하지 않는다.
- 자원 예약은 전체 경로의 최소 필요비용이 아니며, 유용한 기회를 거절할 수 있다.
- 도구 획득이 개선돼도 다른 업적 손실·생존 감소로 개별 에피소드 Return은 낮아질 수 있다.
- 다이아몬드 등 후속 탐험 문제는 남는다. 돌 목표 전체 Return 개선도 불확실하다.
- 강한 Planner가 학습 Skill보다 높은 평균을 기록했다. Skill은 Planner를 성능으로 대체했다고 주장하지 않는다.
- Options·정책 재사용·시작 집합 연구와 계산 원리가 겹친다. 독립적인 새 RL 원리를 확정하지 않는다.
