# 업로드 및 공개 상태

현재는 논문 제출 전의 로컬 파일 준비 단계다. 이 폴더를 만드는 과정에서 원격 저장소 생성·Git push·GitHub Release·외부 파일 업로드를 수행하지 않는다.

## 현재 포함 범위

- 실행 코드, 동결 평가 모델, 고정 설정, 재현 명령.
- 주요 결과표, 원래 정상 게임 평가 CSV, 기존 소규모 재현 검증.
- 선정 논문·원본 저장소 링크, 직접 구현한 수행 내역, 한계.

미제출 원고 전문, 내부 검토 대화, 전체 Phase별 연구일지, 원본 사용자 경로, API 키, 전체 학습 전이는 포함하지 않았다.

## 실제 업로드 전에 팀이 확인할 항목

- 논문 제출 전 공개 가능한 코드·모델·수치 범위와 저장소 공개 범위.
- 팀원 및 저자 표기, 개인별 수행 내역.
- 자체 코드·모델의 공개 라이선스. 제3자 MIT 라이선스는 원문 유지.
- 제출할 보고서·발표자료의 최종 파일과 실제 저장소 주소.

자체 코드의 오픈소스 라이선스를 임의로 부여하지 않았다. 현재 폴더에는 원격 URL이나 자동 게시 설정이 없다. 캡처의 발표자료·일반/논문 형식 보고서는 별도 제출물이며, 이 폴더는 GitHub 포트폴리오 부분을 준비한 것이다.
