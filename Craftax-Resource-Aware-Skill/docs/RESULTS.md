# 결과 정의와 해석

## 주 평가

Phase55는 모델 8쌍, 월드 256개, RNG 두 쌍으로 조건당 4096게임이다. 원래 CSV는 reference/phase55_episodes.csv, 모델별 평균의 t 구간은 results/Table_02.csv에 있다. 같은 평가의 도구·다이아몬드 횟수는 Table_03.csv, Skill 실행 비용·종료 사건은 Table_04.csv에 보존했다.

주지표는 정상 Reset부터 종료까지의 실제 비할인 Raw Return이다. 성공 시연의 평균, 선정 실패 상태의 분기 효과 또는 개입 중 국소 보상과 혼합하지 않는다. 확률적 행동 선택을 Argmax 평가로 바꾸지 않는다.

RULE−B0: +0.229248, 모델 95% t 구간 [+0.174603,+0.283893], 8개 모델쌍 모두 양수. 완료율 43.41→82.08%는 각각 시작 1753/1423게임을 분모로 한다. RULE의 나머지 255건은 종료 코드 2(16스텝) 176건, 4(실행 중 종료/사망 확인) 74건, 3(재료 조건 상실) 5건이다. 종료 코드와 세부 행동 실패 원인은 구분한다.

## 별도 AUTO 평가

Phase56은 다른 월드 64개와 RNG 두 쌍, 조건당 1024게임이다. B0 평균14.44082, G0 14.58633, RULE/AUTO 14.68887이었다. 이 수치를 Phase55의 평균·분모에 합산하지 않는다. AUTO는 보존된 설치 효과 모델의 비용을 계산에 사용한다. 현재 철 과제에서 RULE과 같은 실행을 재현했으므로 두 방법을 독립된 개선 두 건으로 주장하지 않는다.

## 후속 한계

철곡괭이 158→569/4096과 다이아몬드 8→26/4096은 같은 평가의 관측이다. 도구 이후 발견·접근·채굴·생존은 별도 과제다. 낮은 다이아몬드 달성률을 기억 실패나 탐험 부족 하나의 인과효과로 단정하지 않는다.

별도 돌 과제의 전체 Return 차이 +0.05176, 모델 구간[-0.02891,+0.13243]은 확정적인 일반화 이득으로 사용하지 않는다. Planner 직접 호출과 학습 Skill은 추가 계산 비용과 능력이 서로 다르다.
